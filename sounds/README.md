# Real sound recordings

Put audio files in this folder, named as below, and the game plays them instead of its built-in synthesized sounds. You don't need every one: any sound without a file keeps the built-in version. MP3, OGG, WAV and M4A all work (for example `win.mp3` or `win.wav`).

| File name | When it plays |
|---|---|
| `spin` | You press Spin |
| `reelstop` | Each reel stops |
| `win` | Any win (and big wins, if there's no `bigwin`) |
| `bigwin` | Wins of 10× your total bet or more |
| `jackpot` | Serpent Bearer Triple (three Ophiuchus on a line) |
| `megajackpot` | The Mega Jackpot on the Zodiac Wheel |
| `bonus` | A Cosmic Eclipse starts the Zodiac Wheel |
| `wheel` | The Zodiac Wheel spins |
| `freespins` | Free spins are awarded |
| `lose` | A spin with no win |

## Where to find free casino sounds

These sites have slot machine, jackpot and coin payout sounds that are free to use. Check each sound's licence before you use it.

- Pixabay: https://pixabay.com/sound-effects/search/slot%20machine/
- Mixkit: https://mixkit.co/free-sound-effects/casino/
- Freesound (filter by the CC0 licence): https://freesound.org/search/?q=slot+machine+win

## How to add them on GitHub

1. Open this `sounds` folder on github.com.
2. Click **Add file → Upload files** and drag your files in.
3. Rename them to match the table (for example `win.mp3`), then click **Commit changes**.
